# KHI G1 proof evidence

These are small, reproducible artifacts generated by the commands in
[`integrations/khi_g1/README.md`](../../integrations/khi_g1/README.md).

## Verified human-video cases

| Case | Purpose | Timeline | Mean / max marker residual | Max joint speed | Result |
|---|---|---:|---:|---:|---|
| KIT cracker box | Direct table reach baseline | 11 detected frames | 12.9 / 24.9 mm | 0.90 rad/s | lineage pass |
| KIT fruit bars | Side/lateral reach variant | 27 detected + 13 interpolated frames | 10.9 / 33.4 mm | 2.69 rad/s | lineage pass |
| GRAB lateral | Best-quality lateral reach proof | 53/53 detected frames | 8.7 / 22.8 mm | 2.13 rad/s | lineage pass |

The KIT and GRAB clips provide human motion, not robot trajectories. Anchor
extracts the body motion from the video and computes a new G1 trajectory using
the KHI URDF. The robot reference does not depend on a released retargeted
motion file.

| File | Meaning |
|---|---|
| `kit_crackerbox_human_motion_v1.json` | Video-derived body-aligned human landmarks; screening quality |
| `kit_crackerbox_hcs_g1_retarget_v1.json` | HCS-computed G1 29-DoF trajectory |
| `kit_crackerbox_khi_g1_reference.pkl` | KHI joblib-compatible reference |
| `kit_crackerbox_khi_object_reference.pkl` | Key-matched, free-cube initialization companion |
| `anchor_khi_proof_manifest_v1.json` | No-copy SHA-256 lineage manifest |
| `anchor_khi_proof_receipt_v1.json` | Verifier result |

The source video and KHI repository are referenced by absolute path and hash,
not copied here. The current receipt proves technical lineage only. It does
not clear source rights or claim physics/robot success.

Dataset references: [KIT Whole-Body Human Motion Database](https://motion-database.humanoids.kit.edu/)
and [GRAB](https://grab.is.tue.mpg.de/). Rights review is deliberately a
separate release gate and does not block the present internal engineering
proof.
